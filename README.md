# humor-chat-coach · 港式幽默聊天教练

一个 Claude Skill：把你的微信/群聊回复，改写成**黄子华式、张继聪式、峰哥式**三种幽默风格，并告诉你每一句"好笑在哪"，让你下次自己也会用。

核心原则：**拿自己和生活开刀，不拿对方开刀；有自信打底；绝不油腻。**

## 效果示例

对方："今天加班到好晚，好累。"

> 场景判断：对方在轻度吐槽，可以先关心再轻松一下。
>
> 【子华式】辛苦了。加班最惨的地方是，老板并不会因此更爱你。
> → 好笑在：用冷静的"真理"口吻戳破加班的意义
>
> 【继聪式】你这么拼，公司股价今天应该涨了，记得找老板要分红。
> → 好笑在：把她的辛苦夸张成影响股价，顺手站在她这边
>
> 【峰哥式】加班其实是好事，说明公司还需要你。哪天不让你加班了，才真该慌。
> → 好笑在：坏事反转成好事，丧里带通透
>
> ⚠️ 别这样回："心疼你～要不要我抱抱"——关系没到，油且有压力。

## 三种风格

| 风格 | 核心武器 | 适合场景 |
|---|---|---|
| 黄子华式 | 一本正经讲歪理、自嘲不自贬、抽离视角 | 一对一慢聊、对方倾诉 |
| 张继聪式 | 接梗快、夸张但真诚、轻度贱萌 | 群聊、熟人斗嘴 |
| 峰哥式 | 辩证反转、直白、黑色幽默 | 吐槽工作和生活 |


或手动：

```bash
git clone https://github.com/kaibinsiki/humor-chat-coach.git
cp -r humor-chat-coach/skills/humor-chat-coach ~/.claude/skills/
```

**Claude.ai：** 在 Releases 下载 `humor-chat-coach.skill`，到 设置 → Skills 上传。

## 怎么用

装好后直接说：
- "她说'今天好累'，我怎么回？"
- 贴一段聊天记录："帮我看看下一句怎么接"
- "群里在调侃我，帮我接个梗"
